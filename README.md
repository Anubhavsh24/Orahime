# ⏰ OraHime — Digital Clock

A simple and elegant digital clock application built using **HTML, CSS, and JavaScript**.

## 🌐 Live Demo

[**View Live Clock →**](https://Anubhavsh24.github.io/OraHime/)

## 📌 About the Project

OraHime is a digital clock web application designed with a clean and minimal user interface.

This project demonstrates the use of JavaScript for real-time updates, HTML for structuring the application, and CSS for creating an attractive and responsive design.

## ✨ Features

- Real-time digital clock.
- Clean and minimal user interface.
- Automatic time updates using JavaScript.
- Lightweight and easy-to-use application.
- Built with vanilla HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling and layout |
| JavaScript | Clock functionality |

## 🚀 Run Locally

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/Anubhavsh24/OraHime.git
```

**2. Navigate to the project folder**

```bash
cd OraHime
```

**3. Open the project**

Open `index.html` in your browser or use VS Code Live Server.
